# 去你的广告 0.7.17-b7.17

本版本重点修复操作记录缺失、规则状态被错误重置和失败目标重复触发问题，同时收紧通用识别路径，减少普通页面误触。

## 主要变化

- 恢复原始青绿色盾牌图标。
- 已执行动作立即写入带应用身份的本地记录，记录页实时刷新。
- 用户手动操作不再重置规则次数、冷却或匹配时限。
- 失败目标在当前应用会话内隔离，其他安全目标仍可继续匹配。
- 通用辅助识别只接受明确且唯一的广告关闭控件。
- 移除无节点坐标动作、通用返回以及无边界父容器点击。
